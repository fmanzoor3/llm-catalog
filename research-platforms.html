LLM Scoring Platforms & Leaderboards

A comprehensive guide to every major platform that evaluates and ranks large language models.

There is no single "best" leaderboard. Each platform uses different methodologies, covers different models, and measures different things. This page documents the major platforms, what they measure, and how to interpret their scores. See also: Community Scoring vs Benchmarks for analysis of the tradeoffs.

Community / Human Voting Platforms

Arena (LMSYS Chatbot Arena)

arena.ai
Human Voting 600+ Models

The most widely referenced LLM leaderboard. Users chat with two anonymous models side-by-side and vote for the better response. Scores use a Bradley-Terry model (Elo-like scale, ~885–1560). Over 1,000,000 votes collected across 190+ models by 2024. Models need at least 3,000 votes for converged rankings.

9 Separate Arenas: Text, Code (agentic WebDev), Vision, Search, Text-to-Image, Image Edit, Text-to-Video, Image-to-Video, Overview.

Text Leaderboard Categories

Overall Aggregate ranking
Coding Programming tasks
Math Mathematical reasoning
Creative Writing Prose and storytelling
Instruction Following Precise task execution
Hard Prompts Challenging queries
Multi-Turn Conversation quality
Longer Query Extended interactions

8 Occupational Categories: Software & IT, Writing/Literature, Life/Physical/Social Science, Entertainment/Sports/Media, Business/Finance, Mathematical, Legal/Government, Medicine/Healthcare.

Filters: Style Control toggle, License filter (All / Proprietary / Open Source), 8 language filters (English, Chinese, French, German, Spanish, Russian, Japanese, Korean).

Source: Chiang et al., "Chatbot Arena: An Open Platform for Evaluating LLMs by Human Preference," ICML 2024.

Code Arena

arena.ai/leaderboard/code
Human Voting 43 Models

A separate arena from the Chatbot Arena text leaderboard. Tests agentic coding ability — models receive WebDev tasks, use tools, write files, run code, and build applications. 162,000+ votes collected. Scores are Elo-rated but on a different scale than the text arena (typically 1,100–1,560).

Key difference from Chatbot Arena Coding: Chatbot Arena's coding category tests conversational coding (explaining, writing snippets). Code Arena tests actual execution — multi-step reasoning with tool use. Rankings can differ significantly between the two.

OpenRouter Rankings

openrouter.ai/rankings
Usage-Based 300+ Models

Not a benchmark — measures which models developers actually choose and use in production via real API traffic from millions of developers. Rankings by daily, weekly, monthly, and all-time periods.

12 Use-Case Categories: Programming, Roleplay, Marketing, Translation, Finance, Legal, Health, Science, Technology, Trivia, SEO, Academia.

Additional dimensions: Market share by provider, natural language breakdown, programming language breakdown, context length usage, tool call patterns.

Automated Benchmark Platforms

Artificial Analysis

artificialanalysis.ai
Automated 200+ Models

Comprehensive analytics platform with a proprietary Intelligence Index v4.0.2 (composite 0–100 score from 10 benchmarks). Also tracks speed, latency, price, and context window across providers. Updated 8x daily for performance metrics.

Intelligence Index — 4 Categories (25% each)

Agents GDPval-AA (knowledge work), Tau2-Bench (tool-use simulation)
Coding Terminal-Bench Hard (terminal tasks), SciCode (scientific Python)
General Long context reasoning, Omniscience (hallucination), IFBench (instruction following)
Scientific Reasoning Humanity's Last Exam, GPQA Diamond, CritPt (physics)

Comparison axes: Intelligence vs Price, Intelligence vs Speed, Intelligence vs Latency, Intelligence vs Context Window, Speed vs Price.

Source: Intelligence Benchmarking Methodology

LiveBench

livebench.ai
Automated 40–50 Models

A contamination-resistant benchmark that releases new questions monthly from recent sources (arXiv papers, news, IMDb, new datasets). Answers scored against objective ground truth — no LLM judge used. Published as a Spotlight Paper at ICLR 2025. Top models achieve below 70%.

6 Categories (18 Tasks)

Math Mathematical reasoning
Coding Programming tasks
Reasoning Logical and analytical
Data Analysis Working with data
Instruction Following Precise execution
Language Comprehension and processing

Source: White et al., "LiveBench: A Challenging, Contamination-Free LLM Benchmark"

SEAL Leaderboard (Scale AI)

scale.com/leaderboard
Expert + Automated 60+ Models

Expert-driven evaluations using private datasets and human domain specialists. Rankings use 95% confidence interval upper bounds to group models by statistical significance. Published 450+ evaluations across 50+ models.

3 Primary Categories (20 Benchmarks)

Agentic (5) MCP Atlas, SWE-Bench Pro (Public & Private), Remote Labor Index, VisualToolBench
Frontier (11) SciPredict, Humanity's Last Exam, Finance & Legal Reasoning, MultiNRC, EnigmaEval, VISTA, TutorBench
Safety (3) PropensityBench, Fortress (national security), MASK (honesty under pressure)

Hugging Face Open LLM Leaderboard (v2)

huggingface.co
Automated Hundreds

The primary leaderboard for open-source/open-weight models. V2 launched with harder benchmarks after the original became saturated. Scores normalized to 0–100 (0 = random baseline, 100 = perfect). Community-driven — anyone can submit models.

HELM (Stanford CRFM)

crfm.stanford.edu/helm
Automated 30+ Models

Stanford's comprehensive evaluation framework emphasizing transparency and reproducibility. All raw evaluation data is publicly released. Open-source framework covering both LLMs and multimodal models.

7 Evaluation Dimensions (per scenario)

Accuracy Correctness
Calibration Confidence alignment
Robustness Under perturbations
Fairness Across groups
Bias Stereotyping detection
Toxicity Harmful content
Efficiency Computational cost

Evaluates across 42 real-world scenarios spanning medicine, finance, law, and multilingual tasks. Additional variants: HELM Safety, HELM Long Context, SEA-HELM (Southeast Asian languages).

Source: Liang et al., "Holistic Evaluation of Language Models"

Coding-Specific Benchmarks

SWE-bench

swebench.com
Automated 30+ Models

Tests whether models can resolve real GitHub issues — reading issue descriptions, navigating codebases, and producing working patches. Score is percentage of issues resolved (pass@1).

Variants: SWE-bench Lite (300 problems), Verified (500 expert-confirmed), Live (updated monthly with 50 new issues), Pro (by Scale AI, private codebases), Multimodal.

Languages: Python, Go, JavaScript, TypeScript, Rust.

LiveCodeBench

livecodebench.github.io
Automated 65+ Models

Contamination-free code generation benchmark using problems from LeetCode, AtCoder, and CodeForces. Continuously updated with new problems.

Categories: Code generation, self-repair, test output prediction, code execution. Scored via unit test execution (Pass@1 %).

Aider Polyglot Leaderboard

aider.chat
Automated 40+ Models

Tests code editing across 6 programming languages (C++, Go, Java, JavaScript, Python, Rust). 225 Exercism coding exercises. Score is percentage solved (Pass@1).

BigCodeBench

bigcode-bench.github.io
Automated

Practical programming tasks with diverse library dependencies. 1,140 tasks (Full Set) and 150 tasks (Hard Set). Scored via Calibrated Pass@1. Published at ICLR 2025.

Aggregators & Meta-Platforms

LLM-Stats

llm-stats.com

Meta-aggregator tracking results across all major benchmarks and arenas. Consolidates coding, math, writing, image generation, and more into one interface.

Vellum LLM Leaderboard

vellum.ai/llm-leaderboard

Aggregates latest benchmarks for models released after April 2024. Includes cost, speed, context window alongside quality scores. Covers LiveCodeBench, Aider Polyglot, SWE-bench, BFCL tool use, and more.

Klu AI Leaderboard

klu.ai/llm-leaderboard

Practical comparison of 30+ frontier models across cost, speed, and quality. Tracks both frontier benchmarks (BigCodeBench, MATH, GPQA, GAIA) and standard benchmarks (MMLU, HumanEval, GSM8K).

Other Notable Benchmarks

FrontierMath (Epoch AI)

epoch.ai/frontiermath

Expert-level mathematics from undergraduate to research-level. 350 problems across 4 tiers (Tier 4 = unsolved research problems). Private evaluation set to prevent contamination.

AlpacaEval 2.0

tatsu-lab.github.io/alpaca_eval

Automated evaluator for instruction-following. Uses GPT-4 as auto-annotator with a Length-Controlled Win Rate metric (debiased against length preferences). 100+ models evaluated.

MT-Bench

huggingface.co

Multi-turn conversation quality benchmark. 80 questions across 8 categories: Writing, Roleplay, Extraction, Reasoning, Math, Coding, STEM Knowledge, Humanities Knowledge. Scored 1–10 by GPT-4.

Source: Zheng et al., "Judging LLM-as-a-Judge with MT-Bench and Chatbot Arena", NeurIPS 2023.

WildBench (Allen AI)

huggingface.co

Real-world challenging user queries (1,024 tasks from 1M+ conversation logs). Uses GPT-4-Turbo as judge. Scores via WB-Reward (pairwise comparison) and WB-Score (individual quality). Published at ICLR 2025.
