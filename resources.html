Model Scoring

How the 0–100 use case scores are calculated, and which metrics drive each score.

▼

Each use case gets a composite score from 0 to 100 based on a weighted blend of community ratings (Chatbot Arena Elo) and benchmarks (SWE-bench, GPQA, AIME, etc.). Each metric is normalized to a 0–100 scale using fixed bounds, then multiplied by its weight.

Why these weights? We blend two complementary signal types: benchmarks measure specific, reproducible skills (coding, math, science), while community ratings capture real-world usability that benchmarks miss (tone, helpfulness, instruction-following). Metrics that directly test the use case get the highest weight — for example, SWE-bench and Arena Coding together drive 65% of the coding score. Context window and multimodal capability are included where they meaningfully affect the task. Speed is shown separately and does not influence quality scores. For a deeper discussion of these trade-offs, see our scoring research page.

Missing data handling: When a model has 60% or more of the weighted metrics available, scores are rescaled so available data fills the full range. Below 60%, missing metrics contribute zero — naturally lowering the score. This means newly released models with limited evaluation data will score lower until more benchmarks and community ratings are published.

Practical factors: Context window is log-scaled (larger windows have diminishing returns). Multimodal capability is treated as a bonus factor for relevant use cases.

Community Votes Reference

Why blind human preference votes are a credible signal, and how we use them alongside benchmarks.

▼

Community leaderboards like LM Arena rank models using blind human preference votes rather than automated tests. Users submit a prompt and see two anonymous model responses side by side — they vote for the better one without knowing which model produced it.

These pairwise comparisons are aggregated into Elo ratings (the same system used in chess) using a statistical model called Bradley–Terry that controls for response style and length bias. With over 3.5 million votes, Arena Elo scores are a strong signal for real-world quality — especially for subjective tasks like creative writing, chatbots, and instruction following where automated benchmarks fall short.

We incorporate Arena scores alongside traditional benchmarks because they capture dimensions that automated tests miss: helpfulness, coherence, tone, and the ability to follow nuanced instructions. Each use case uses the most relevant Arena sub-category rather than just the overall score.

Arena categories we use in scoring:

Arena Overall

The general-purpose Elo rating across all prompt types. Captures broad conversational quality and is used as a baseline signal across most use cases.
