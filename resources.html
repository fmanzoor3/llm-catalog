Methodology

How Scoring Works

How the 0–100 use case scores are calculated, and which metrics drive each score.

▼

Each use case gets a composite score from 0 to 100. We normalize each metric to a 0–1 range using fixed bounds, multiply by its weight, and sum the results. Context window uses logarithmic scaling. Speed and multimodal support contribute as binary factors.

Benchmark Reference

What each benchmark measures, how to interpret the scores, and where to find the original data.

▼

SWE-bench Verified

Can the model resolve real GitHub issues? It reads an issue, navigates the codebase, and must produce a working patch. Score is % of issues resolved.

swebench.com ↗

GPQA Diamond

PhD-level science questions in biology, physics, and chemistry. Designed to be hard even for domain experts. Score is % correct.

AIME 2024

Problems from the American Invitational Mathematics Examination. Tests advanced math reasoning — algebra, geometry, number theory, combinatorics.

Multi-language code editing. The model must follow instructions to produce correct code changes across Python, JavaScript, Go, Java, and more.

MATH-500

500 math problems spanning algebra, geometry, number theory, and calculus. A broad test of mathematical problem-solving ability.
